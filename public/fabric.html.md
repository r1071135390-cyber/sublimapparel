**Last updated:** 2025-08-18 · **Author:** Ramon Wang, Sales Director

## Answer capsule
Most apparel projects start with **two questions**: what fabric and what print process. For all-over photorealistic print on polyester, use **sublimation**. For photorealistic print edge-to-edge on cotton, use **allover digital print on cotton (cut-and-sew)**. For a logo or short-run panel print on cotton, use **DTG (≥50 pcs) or DTF (≥50 pcs)**. For a vintage soft hand on cotton at volume, use **screen print (≥200 pcs)**.

## 6 print processes (in-house)
1. [Sublimation](https://sublimapparel.com/technique/#sublimation) — for polyester, all-over, photorealistic
2. [Allover digital print on cotton](https://sublimapparel.com/technique/#allover-digital-cotton) — for cotton, true full-body
3. [DTG](https://sublimapparel.com/technique/#dtg) — for cotton, A4–A3 per panel, low MOQ
4. [DTF](https://sublimapparel.com/technique/#dtf) — for any fabric, vibrant colors, low MOQ
5. [Screen printing](https://sublimapparel.com/technique/#screen) — for cotton, ≥200 pcs, vintage soft hand
6. [Embroidery](https://sublimapparel.com/technique/#embroidery) — for caps, polos, hoodies, workwear

## Sublimation fit rating
Each fabric page lists a "Sublimation fit" score: **S (best) / A (great) / B (good) / C (avoid)**. Use S/A fabrics for true all-over print; B works for position print; C is not recommended for sublimation.
