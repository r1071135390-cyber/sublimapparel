# Business Discovery Checklist

在动手之前，先向用户收集这些信息。这一步是项目成败的关键——信息不全，网站就是空壳。

## 必备信息（不可跳过）

### 1. 公司业务
- [ ] 公司名（中英文）
- [ ] 主营业务（一句话描述）
- [ ] 工厂位置（中国哪个城市/区域）
- [ ] 工厂规模（员工数、产线数、厂房面积）
- [ ] 月产能（件/月）
- [ ] 主要产品类别（5-10 个大类）

### 2. 目标客户
- [ ] 主要销售地区（北美 / 欧洲 / 澳洲 / 全球）
- [ ] 客户类型（赛事承办商、广告商、品牌商、批发商、Pod平台、其他）
- [ ] 客户主要关心的点（价格？质量？交期？定制能力？）

### 3. 核心卖点（必须明确）
- [ ] MOQ 起订量
- [ ] 交期（生产天数 + 物流天数）
- [ ] 物流方式（DDP / FOB / EXW？仓在哪？）
- [ ] 是否提供样品
- [ ] 付款方式（T/T、L/C、PayPal？30/70？）
- [ ] 认证（BSCI、Sedex、ISO、OEKO-TEX？）

### 4. 现有素材
- [ ] 工厂实拍图（车间、设备、产线）
- [ ] 产品图（成品、白底、模特、细节）
- [ ] logo（SVG/PNG 透明底）
- [ ] 公司视频（可选）
- [ ] 客户案例（合作过哪些大客户？如有可截图）
- [ ] 认证证书扫描件

### 5. 域名 & 部署
- [ ] 主域名（如 chinarhinestone.com）
- [ ] DNS 在哪（Cloudflare / 其他注册商）
- [ ] 是否要备案（外贸英文站一般不用）
- [ ] 邮箱用什么（QQ企业邮箱 / Google Workspace / 自己的邮件服务器）

### 6. 旧站情况（如有）
- [ ] 老站 URL 是什么
- [ ] 老站是否还有流量
- [ ] 哪些老内容要保留
- [ ] 老站什么时候下线

## 收集方式

**直接问用户**（不要让用户填表）。问题示例：

> "你们工厂主要做什么产品？MOQ 多少？交期多久？主要卖给哪类客户？"
>
> "工厂大概多大？几条产线？月产多少件？"
>
> "你这边有工厂实拍图吗？或者产品图？logo 给我一份？"

**做笔记** — 后续每个页面的文案都从这些信息里来。

## 信息不全时怎么办

如果用户某项答不上来：
- **不要瞎编** — 数据造假对 B2B 是致命的
- **给默认值** — 比如 "未指定" 或 "联系我们"
- **建议方向** — 比如 "建议至少拍 5 张车间实拍图"

## sublimapparel.com 真实数据参考

```
公司名: Yiwu SublimApparel (义乌升华印花)
工厂位置: 义乌 + 洛杉矶仓
月产能: 80,000 件 / 月
核心 MOQ: 50 件
交期: 7-15 天生产 + 5-10 天 DDP
目标客户: 欧美 B2B（赛事、广告、品牌、POD）
认证: 工厂通过 Wal-Mart / Disney FAMA 审核
```

可以作为你给用户的回答模板。
